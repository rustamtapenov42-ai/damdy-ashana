# Damdy Ashana — журнал приёма продуктов

Веб-приложение для столовой: каждая принятая партия — отдельная запись с накладной, декларацией, фото, сроком годности и оценкой. Интерфейс на русском и казахском, удобно заполнять с телефона.

**Разделы**
- **Приём продуктов** — журнал за день, поиск, фильтр по оценке, карточка партии, печать журнала (А4, альбомная), выгрузка в Excel.
- **Обзор** — поступления сегодня, партии с истекающим (≤ 2 дня) и просроченным сроком, последние приёмы.
- **Поставщики** — справочник (общий с модулем столовой), число поставок и отказов за год.
- **Документы** — все накладные и декларации за месяц.
- **Отчёты** — партии по дням, принято по продуктам, отказы по поставщикам, Excel за месяц.

Изменения видны сразу на всех устройствах (Supabase Realtime).

## Как устроено

- React + TypeScript + Vite, без серверного кода.
- База и вход — существующий проект Supabase (`lojsuvtkrazwdcwcxtqy`). Журнал живёт рядом с модулем столовой и использует его роли и права:
  - **«Просмотр столовой»** (`canteen.view`) — видеть журнал, документы, отчёты;
  - **«Управление столовой»** (`canteen.manage`) — принимать продукты, править и удалять записи, добавлять поставщиков.
  - Роль `org_rep` видит только свою организацию; `superadmin` и `director` — все (в меню появляется выбор организации).
- Таблица `canteen_receipts`, закрытое хранилище файлов `canteen` (путь `<org_id>/<receipt_id>/<файл>`). SQL — в `supabase/migrations/`.

## Запуск на компьютере

```bash
npm install
cp .env.example .env.local   # адрес проекта и публичный ключ уже вписаны
npm run dev
```

## Публикация в интернет (Vercel, бесплатно)

1. Зайдите на [vercel.com](https://vercel.com) через GitHub → **Add New → Project** → выберите этот репозиторий.
2. В **Environment Variables** добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` (значения — из `.env.example`).
3. **Deploy**. Через минуту появится адрес вида `damdy-ashana.vercel.app`.
4. В Supabase → **Authentication → URL Configuration** добавьте этот адрес в *Site URL* / *Redirect URLs*.

На телефоне откройте адрес и выберите «На экран “Домой”» — журнал откроется как приложение.

## Как дать доступ сотрудникам

1. Supabase → **Authentication → Users → Add user** (email и пароль) — или через раздел пользователей в основной системе.
2. В таблице `profiles` поставьте сотруднику роль `org_rep` и `org_id` организации-столовой (у роли `org_rep` уже есть право «Управление столовой»).
